# HARAnalyzer V3
The tools does:
- HAR frame viewer
- Converts a Fiddler SAZ (Session Archive Zip) file to HAR format (HTTP archive)
- ZIPs the HAR file to the same folder where the HAR file is
- Statistics and timeline for each HTTP request
- added: protocol version
- added: frame number
